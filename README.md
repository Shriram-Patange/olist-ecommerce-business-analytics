# 🛒 Olist E-Commerce Business Analytics

## 📊 Project Overview

An end-to-end E-Commerce Business Analytics project using **SQL and Power BI** to analyze sales, customers, products, sellers, payments, reviews, and delivery performance.

## 🛠️ Tools Used

- SQL / MySQL
- Power BI
- DAX
- Power Query
- Excel / CSV

## 🎯 Key Analysis

- Total Revenue & Orders
- Monthly Revenue Trends
- Revenue by State
- Top Product Categories
- Customer Analysis
- Seller Performance
- Payment Analysis
- Customer Ratings
- Order & Delivery Performance
